## Overview

**Scaling Mode** is a high-performance operating mode for TabPFN-2.5 that removes fixed constraints on dataset size. While the standard model is evaluated for up to 100,000 rows, Scaling Mode allows the foundation model to scale to orders of magnitude larger workloads.

## Key Capabilities

* **Massive Dataset Support**: Delivers strong performance on datasets with up to **10 million data points**.
* **Performance Gains**: Maintains the performance gap over gradient boosting libraries as data scales, outperforming naive subsampling approaches.
* **Feature Capacity**: Keeps the robust **2,000-feature limit** introduced with TabPFN-2.5.
* **In-Context Learning**: Continues to provide training-free, "one forward pass" predictions without the need for dataset-specific hyperparameter tuning.

## Evolution of Scale

The following table summarizes the recommended operating regimes as the technology has evolved:

| Version | Recommended Row Limit | Recommended Feature Limit |
| :--- | :--- | :--- |
| TabPFN v1 | 1,000 rows | 100 features |
| TabPFNv2 | 10,000 rows | 500 features |
| TabPFN-2.5 | 100,000 rows | 2,000 features |
| **Scaling Mode** | **10,000,000+ rows** | **2,000 features** |
