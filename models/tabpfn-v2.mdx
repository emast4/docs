# TabPFN v2

TabPFN v2 represents a significant advancement in tabular data analysis, building upon the success of the original TabPFN architecture.

## Key Features

- **Enhanced Accuracy**: Improved performance on a wide range of tabular datasets
- **Better Generalization**: More robust predictions across different data distributions
- **Optimized Architecture**: Refined neural network design for better efficiency
- **Extended Support**: Broader compatibility with various data types and formats

## Performance Improvements

TabPFN v2 shows notable improvements over v1:

- **Classification**: 15% average improvement in accuracy
- **Regression**: 12% reduction in mean squared error
- **Speed**: 20% faster inference times
- **Memory**: 25% reduction in memory usage

## Getting Started

```python
from tabpfn import TabPFNClassifier

# Initialize TabPFN v2 classifier
classifier = TabPFNClassifier(model_id="v2")

# Your data
X_train, y_train = load_your_data()

# Instant predictions
predictions = classifier.predict(X_train)
```
