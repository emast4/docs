# TabPFN v3

TabPFN v3 is the most advanced version yet, featuring cutting-edge improvements in accuracy, speed, and versatility.

- **Adaptive Architecture**: Automatically adjusts to your data characteristics
- **Zero-Shot Learning**: Works on completely unseen data types
- **Interpretability**: Built-in feature importance and model explanations

## Quick Example

```python
from tabpfn import TabPFNMultiTask

# Initialize multi-task model
model = TabPFNMultiTask(model_id="v3")

# Handle different tasks with the same model
classification_results = model.predict(X_cls, task="classification")
regression_results = model.predict(X_reg, task="regression")
forecasting_results = model.predict(X_ts, task="forecasting")
```
