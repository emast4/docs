## Welcome to Prior Labs
TabPFN is a **tabular foundation model** - providing state-of-the-art predictions across thousands of use-cases in seconds.
It is a pre-trained transformer trained on billions of synthetic datasets to learn the learning process itself. Instead of optimizing weights for every new dataset, TabPFN already encodes the inductive biases, priors, and optimization strategies that traditional models must rediscover each time. When you run it on your data, it uses in-context learning to make predictions in a single neural network forward pass - producing predictions in seconds that match or exceed the accuracy of tuned ensembles trained for hours.
