# Welcome to Prior Labs
TabPFN is a **foundation model for tabular data** - built to replace manual model tuning with instant, state-of-the-art predictions.

It’s trained across millions of synthetic datasets to learn the learning process itself. Instead of optimizing weights for every new dataset, TabPFN already encodes the inductive biases, priors, and optimization strategies that traditional models must rediscover each time.
When you run it on your data, it performs **zero-shot inference** - producing predictions in seconds that match or exceed the accuracy of tuned ensembles trained for hours.
