# Welcome to Prior Labs
TabPFN is a **foundation model for tabular data** - built to replace manual model tuning with instant, state-of-the-art predictions.

It’s trained across millions of synthetic datasets to learn the learning process itself. Instead of optimizing weights for every new dataset, TabPFN already encodes the inductive biases, priors, and optimization strategies that traditional models must rediscover each time.
When you run it on your data, it performs **zero-shot inference** - producing predictions in seconds that match or exceed the accuracy of tuned ensembles trained for hours.

## 🚀 How to Use TabPFN
TabPFN can be used in two ways - depending on your workflow and compute setup.

Whether you’re experimenting locally, integrating into a pipeline, or deploying at scale, there’s a path that fits.

### 1. Open Source Package

**Best for**: researchers, ML practitioners, and engineers with local GPU or cluster access.

TabPFN is available as an open-source Python package on [GitHub](https://github.com/priorlabs/tabpfn). It provides the full model locally, giving you complete control over inference and experimentation.

```bash
pip install tabpfn
```

```python
from tabpfn import TabPFNClassifier

model = TabPFNClassifier()
model.fit(X_train, y_train)
preds = model.predict(X_test)
```

<Note>GPU recommended (e.g., NVIDIA T4 at minimum or A100/H100) for optimal inference speed.</Note>

### 2. TabPFN API
**Best for**: data teams and developers who want TabPFN’s performance without managing infrastructure.

The Prior Labs API provides cloud-hosted access to TabPFN 2.5 - we handle all GPU compute, scaling, and model versioning.

You can use it either through a REST API or our Python SDK.

#### Using the REST API

```python
import os, json, requests

x_test_path = "x_test.csv"  # your test dataset
api_key = os.getenv("PRIORLABS_API_KEY")

payload = {
    "task": "classification",
    "model_id": "123e4567-e89b-12d3-a456-426614174000",
}

with open(x_test_path, "rb") as f:
    files = {
        "data": (None, json.dumps(payload), "application/json"),
        "file": (x_test_path, f, "text/csv"),
    }
    response = requests.post(
        "https://api.priorlabs.ai/v1/predict",
        headers={"Authorization": f"Bearer {api_key}"},
        files=files,
    )

print(response.json())
```

#### Using the Python SDK

```python
import tabpfn_client
from tabpfn_client import TabPFNClassifier, TabPFNRegressor

# Authenticate using your Prior Labs token
tabpfn_client.set_access_token("YOUR_API_KEY")

# Use TabPFN like any scikit-learn model
model = TabPFNClassifier()
model.fit(X_train, y_train)

# Get predictions
preds = model.predict(X_test)
```
