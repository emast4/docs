## How It Works

TabPFN converts raw operational data into anomaly detection models. It processes system metrics, performance indicators, user activity, and process parameters to identify unusual patterns before they cause downtime or quality issues.

The table below lists typical input signal categories used for anomaly detection:

<div className="table-container-dc3e57e5">
| System Metrics         | Process Data             |
| ---------------------- | ------------------------ |
| Performance indicators | Quality measurements     |
| Error rates and logs   | Equipment parameters     |
| Resource utilization   | Environmental conditions |
| Network traffic        | Production schedules     |

</div>

## Why Operations Teams Choose TabPFN

### **Anomaly Detection and Forecasting**

- Detects statistical deviations across system metrics, process parameters, and performance indicators
- Works with heterogeneous tabular data, including numerical, categorical, and missing values
- Applicable to equipment monitoring, process drift detection, and production quality control

### **Noise Reduction and False Positive Control**

- Learns non-linear dependencies across correlated signals to filter noise
- Improves distinction between true anomalies and expected operational variation
- Reduces false positives compared to rule-based and threshold-based systems
