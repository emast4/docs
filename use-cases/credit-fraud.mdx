## How It Works

Detect fraudulent transactions using payment patterns and behavioral data. TabPFN analyzes transaction amounts, merchant categories, geographic patterns, and user behavior to identify fraud risk.

The following table summarizes key data types leveraged when building credit fraud detection models. Integrating both transaction-level and behavioral data enables TabPFN to capture complex fraud signals, supporting highly accurate and timely fraud detection.
