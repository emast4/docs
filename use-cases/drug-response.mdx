## How It Works

Predict drug response using genomic and clinical data. TabPFN analyzes patient profiles including mutation data, gene expression, and clinical history to identify treatment patterns, supporting clinical decision-making with quantified predictions.

The following table summarizes common data types used when building drug response predictors. Integrating both genomic and clinical data helps capture patient response complexity, enabling data-driven treatment insights.

<div className="table-container-dc3e57e5">
| Genomic Data         | Clinical Records     |
| -------------------- | -------------------- |
| Mutation profiles    | Patient demographics |
| Gene expression      | Medical history      |
| Biomarker panels     | Laboratory values    |
| Methylation patterns | Imaging results      |

</div>

## Why Healthcare Teams Choose TabPFN?

### **Robust Performance on Clinical Data Sparsity**

- Handles missing genomic markers and incomplete clinical records natively
- Zero-shot inference on out-of-distribution patient populations
- Stable predictions with small cohort sizes (≤10k samples) where traditional ML overfits

### **Domain Adaptation Through Fine-Tuning**

- Adapt pretrained transformer weights to specific patient demographics
- Fine-tune on institution-specific protocols and clinical contexts
- Retain foundation model priors while specializing for population-specific patterns

### **Unified Transformer Architecture**

- Single 18-layer alternating attention model handles classification and regression tasks
- Replace ensemble pipelines with one foundation model across prediction workflows
- Eliminates model selection and hyperparameter optimization overhead

### **In-Context Learning for Clinical Research**

- No extended training cycles or retraining needed
- Immediate inference on new patient data without retraining cycles
- Calibrated probabilities for uncertainty-aware clinical decision support

## **Frequently Asked Questions**

<Accordion title="How does TabPFN enhance treatment prediction?">
  - Alternating row-feature attention captures complex genomic-clinical dependencies

<Accordion title="Can TabPFN work with incomplete patient data?">
  Yes! TabPFN handles missing values and incomplete records automatically, making it practical for real-world clinical settings where complete data isn't always available.

  - Pretrained on synthetic datasets with realistic missing value patterns
  - Native support for `pd.NA` and mixed data types without imputation pipelines
</Accordion>
